# Spell art references

The spell cards use the Deltarune spell names and mechanics as inspiration, but this repository does **not** bundle ripped Deltarune sprites, screenshots, music, or other copyrighted game assets.

Reference material used while designing the cards:

- Heal Prayer mechanics: https://deltarune.wiki/w/Heal_Prayer
- Rude Buster mechanics: https://deltarune.wiki/w/Rude_Buster
- Spell overview: https://deltarune.wiki/w/Spells

The intended final card art is original fan-made artwork based on the spell concepts. The game will fall back to the normal card presentation until local portrait assets are supplied.
